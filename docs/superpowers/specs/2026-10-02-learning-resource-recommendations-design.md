# 学习资源推荐设计规格

**日期：** 2026-10-02  
**状态：** 用户已确认规格，实施完成  
**依据：** 现有可调整周期行动计划与 `data/knowledge/learning_resources/` 中已整理的公开学习资料

## 目标

在行动计划的具体任务下附上少量相关课程或学习资料，帮助学生知道去哪里学习、资源适合解决什么问题，同时保证链接来自已整理的知识库资料。

## 用户体验

- 每个计划任务最多显示 2 项学习资源，放在该任务的完成标准之后。
- 每项资源显示标题、来源名称、简短学习用途、语言或费用提示，以及可点击的来源链接。
- 下载的 Markdown 计划在对应任务下保留同样的资源标题、用途和链接。
- 找不到匹配资源时不显示空推荐区，也不使用模型编造课程或链接。
- 如果计划本身是本地演示回退内容，资源建议仍标明其来源状态，不暗示链接已被项目组完整审核。

## 资料与匹配

- 推荐范围限定为 `data/knowledge/learning_resources/` 中明确标记为 `document_type: learning_resource` 的资料；暂不在计划生成时实时搜索互联网。
- 匹配以计划岗位类别及单项任务标题、说明和完成标准为输入，并只检索该岗位及 `all` 类别资料。
- 优先按检索相关度选取最多 2 项；同一资源只有在确实匹配不同任务时才可重复出现。
- 使用资料文件中保存的标题、来源、链接、语言/费用提示和用途说明；链接必须与知识库记录一致。
- 向量检索不可用时沿用项目现有关键词检索回退；仍无匹配则不推荐。
- 检索结果保留 `review_status` 和更新时间等既有来源元数据。`verified` 的含义继续遵循现有项目约定，不将链接可访问误写为内容认证。

## 数据结构与接口

- 每项任务新增可选 `learning_resources` 数组。
- 每个推荐项至少包含 `id`、`title`、`source_name`、`source_url`、`recommendation_hint`、`language`、`access_note`、`review_status` 和 `updated_at`。
- 空数组与字段缺失都视为没有推荐，不影响旧版已保存计划的读取和显示。
- 计划生成结束后由后端依据任务检索并附加资料；不要求语言模型生成 URL 或资源元数据。

## 页面与导出

- 行动计划页将推荐放在对应任务卡片内，使用“学习资料”标题和简洁链接行，不新增独立侧栏或新的顶级页面。
- 页面只显示实际存在的提示字段；语言或费用信息缺失时不猜测。
- Markdown 下载中每条推荐成为任务下的项目链接，并附简短用途和可用的访问提示。
- 历史计划缺少 `learning_resources` 时按原样显示，不报错。

## 错误处理与边界

- 检索失败不得使计划生成失败；继续返回计划，只是不附推荐。
- 缺少 URL 的资料不得作为可点击课程推荐。
- 不自动宣称课程免费、中文或适合初学者，除非对应资料记录明确提供该信息。
- 不在本版实现实时网页爬取、自动课程排名、进度追踪或报名跳转。

## 验收标准

1. 有匹配资料时，计划任务显示最多 2 条真实知识库来源链接，并提供来源和用途说明。
2. 不同岗位只匹配自身类别和 `all` 类资源。
3. 没有合适或带链接的资源时，计划仍能正常生成且不显示虚构链接。
4. 向量服务不可用时可以使用关键词检索；检索异常时计划仍能正常返回。
5. 页面展示和 Markdown 导出都将推荐放在对应任务下。
6. 旧历史计划没有推荐字段时仍能正常读取、显示和导出。
