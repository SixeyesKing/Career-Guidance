# 非运行资料归档

这里集中保存与网站运行无关的项目材料，文件内容和原有子目录结构均已保留。

- `知识库/`：原始岗位台账与指南；`scripts/prepare_knowledge.py` 从这里生成 `data/knowledge/generated/`。
- `docs/`、`content/`、`.superpowers/`：历史设计规格、实施计划和页面草稿。
- `就业指导要求/`、`2026-09-29/`、根目录的 Markdown 和 Excel 文件：课程要求、项目计划与参考资料。
- `.codex-pitch-build/`、`.codex-finalizer/`、`exports/`：路演制作过程文件、演示文稿、截图及日志。
- `.agents/`：曾用于界面设计的本地工具资料。

运行网站仍从项目根目录使用 `start.bat`，或者按根目录 `README.md` 的前后端命令启动。
