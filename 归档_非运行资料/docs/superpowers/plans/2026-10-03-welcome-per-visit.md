# 每次访问从欢迎状态开始

用户要求：之前的数据不再成为每次进入网页的默认数据。

实现：Streamlit 的每个新会话生成随机访问标识，控件重跑和站内导航复用该标识；新标签页、重新进入或点击右上角“重新开始”生成新标识。API 通过请求上下文选择独立 SQLite 文件，画像、分析、对话、体验和计划全部使用本次访问的数据。知识库与模型配置共享，原数据库保留。无访问标识的既有 API 调用保持兼容。

不增加自动恢复或登录流程。页面明确提示刷新会开启新探索，计划可以先下载。访问标识用于本地数据分组，不是账号认证。

实施与验证：

- [x] 前端传递会话标识，显示欢迎与本次记录文案。
- [x] 空白访问只展示欢迎入口；点击“开始填写个人画像”后进入画像表单，右上角可随时重新开始。
- [x] 后端验证标识，通过 ContextVar 隔离存储并恢复请求上下文。
- [x] 验证同次访问持续保存、新访问数据为空、旧库未被修改、并发不串数据。
- [x] 运行已有 UI 回归检查，重启本地服务并检查真实欢迎页。

## 验收结果

13 项测试全部通过。新访问或点击“重新开始”后显示欢迎页；访问内导航仍保留当前填写，页面实际桌面宽度无横向溢出。原有数据库不被修改，临时访问库已加入 `data/sessions/` 忽略规则。
