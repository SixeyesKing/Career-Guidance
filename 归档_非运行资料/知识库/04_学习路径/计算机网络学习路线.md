# 计算机网络学习路线

## 岗位类别
后端开发/前端开发/测试开发

## 资料类型
学习路径

## 正文内容

### 一、学习路线总览

```
网络基础 → TCP/IP → HTTP协议 → HTTPS → 网络编程 → 网络安全
```

### 二、各阶段详细内容

#### 阶段一：网络基础（1-2周）

**学习内容**：
- 计算机网络概述
- 网络分层模型
  - OSI七层模型
  - TCP/IP四层模型
- 网络设备
  - 集线器
  - 交换机
  - 路由器

**推荐资源**：
- 书籍：《计算机网络：自顶向下方法》
- 视频：哈工大计算机网络

**学习目标**：
- 理解网络分层模型
- 了解网络设备
- 掌握基本概念

#### 阶段二：TCP/IP（2-3周）

**学习内容**：
- IP协议
  - IP地址
  - 子网掩码
  - 路由
- TCP协议
  - 三次握手
  - 四次挥手
  - 流量控制
  - 拥塞控制
- UDP协议
  - 特点
  - 应用场景

**推荐资源**：
- 书籍：《TCP/IP详解》
- 视频：计算机网络微课堂

**学习目标**：
- 理解IP协议
- 掌握TCP协议
- 了解UDP协议

#### 阶段三：HTTP协议（1-2周）

**学习内容**：
- HTTP请求
  - 请求方法（GET、POST、PUT、DELETE）
  - 请求头
  - 请求体
- HTTP响应
  - 状态码
  - 响应头
  - 响应体
- HTTP版本
  - HTTP/1.0
  - HTTP/1.1
  - HTTP/2
  - HTTP/3

**推荐资源**：
- 书籍：《图解HTTP》
- MDN文档：https://developer.mozilla.org/zh-CN/docs/Web/HTTP

**学习目标**：
- 理解HTTP协议
- 掌握请求和响应
- 了解HTTP版本

#### 阶段四：HTTPS（1周）

**学习内容**：
- SSL/TLS
- 数字证书
- 加密算法
- HTTPS握手过程

**推荐资源**：
- 书籍：《图解密码技术》

**学习目标**：
- 理解HTTPS原理
- 了解加密算法
- 掌握握手过程

#### 阶段五：网络编程（2-3周）

**学习内容**：
- Socket编程
  - TCP Socket
  - UDP Socket
- IO模型
  - 阻塞IO
  - 非阻塞IO
  - IO多路复用
  - 异步IO
- 网络框架
  - Netty
  - Nginx

**推荐资源**：
- 书籍：《Netty实战》
- 视频：尚硅谷Netty

**学习目标**：
- 掌握Socket编程
- 理解IO模型
- 了解网络框架

#### 阶段六：网络安全（1-2周）

**学习内容**：
- 常见攻击
  - SQL注入
  - XSS
  - CSRF
  - DDoS
- 防御措施
  - 输入验证
  - 参数化查询
  - CSP
  - 防火墙

**推荐资源**：
- 书籍：《白帽子讲Web安全》

**学习目标**：
- 了解常见攻击
- 掌握防御措施
- 能编写安全代码

### 三、学习时间规划

**总时间**：2-3个月

| 阶段 | 时间 | 内容 |
|------|------|------|
| 第1阶段 | 1-2周 | 网络基础 |
| 第2阶段 | 2-3周 | TCP/IP |
| 第3阶段 | 1-2周 | HTTP协议 |
| 第4阶段 | 1周 | HTTPS |
| 第5阶段 | 2-3周 | 网络编程 |
| 第6阶段 | 1-2周 | 网络安全 |

### 四、计算机网络面试重点

#### 1. TCP/IP
- TCP三次握手
- TCP四次挥手
- TCP和UDP的区别
- 流量控制和拥塞控制

#### 2. HTTP
- HTTP请求方法
- HTTP状态码
- HTTP和HTTPS的区别
- HTTP版本

#### 3. 网络编程
- Socket编程
- IO模型
- IO多路复用
