# Java后端学习路线

## 岗位类别
后端开发

## 资料类型
学习路径

## 正文内容

### 一、学习路线总览

```
Java基础 → 数据库 → Web开发 → 框架学习 → 项目实战 → 进阶提升
```

### 二、各阶段详细内容

#### 阶段一：Java基础（4-6周）

**学习内容**：
- Java语法基础
- 面向对象编程（封装、继承、多态）
- 集合框架（List、Set、Map）
- 异常处理
- IO流
- 多线程基础
- 反射和注解

**推荐资源**：
- 书籍：《Java核心技术》《Head First Java》
- 视频：尚硅谷Java基础、黑马程序员Java基础
- 练习：LeetCode简单题

**学习目标**：
- 能独立编写Java程序
- 理解面向对象思想
- 熟悉常用集合类

#### 阶段二：数据库（2-3周）

**学习内容**：
- SQL语法（增删改查）
- MySQL数据库
  - 索引原理与优化
  - 事务与锁
  - 存储引擎
  - 慢查询优化
- Redis缓存
  - 数据结构
  - 持久化
  - 缓存策略
  - 分布式锁

**推荐资源**：
- 书籍：《MySQL必知必会》《Redis设计与实现》
- 视频：尚硅谷MySQL、黑马程序员Redis

**学习目标**：
- 熟练编写SQL语句
- 理解索引原理
- 掌握Redis基本使用

#### 阶段三：Web开发（3-4周）

**学习内容**：
- HTML/CSS/JavaScript基础
- HTTP协议
- Servlet/JSP（了解）
- Spring Boot
  - IoC/DI
  - AOP
  - MVC
  - 自动配置
- MyBatis
  - XML映射
  - 注解开发
  - 动态SQL

**推荐资源**：
- 书籍：《Spring实战》《MyBatis从入门到精通》
- 视频：尚硅谷Spring Boot、黑马程序员Spring Boot

**学习目标**：
- 能独立开发Web应用
- 理解MVC架构
- 掌握Spring Boot核心功能

#### 阶段四：框架学习（4-6周）

**学习内容**：
- Spring Cloud微服务
  - 注册中心（Nacos/Eureka）
  - 配置中心（Nacos Config）
  - 网关（Spring Cloud Gateway）
  - 远程调用（OpenFeign）
  - 熔断降级（Sentinel）
- 中间件
  - 消息队列（Kafka/RabbitMQ）
  - 分布式事务（Seata）
  - 分布式ID（雪花算法）
  - 分布式锁（Redis/Zookeeper）

**推荐资源**：
- 书籍：《Spring Cloud微服务实战》
- 视频：尚硅谷Spring Cloud

**学习目标**：
- 理解微服务架构
- 掌握常用中间件
- 能设计简单的分布式系统

#### 阶段五：项目实战（4-6周）

**项目推荐**：
- 个人博客系统
- 在线商城系统
- 短链接系统
- 即时通讯系统
- 文件存储系统

**项目要求**：
- 使用Spring Boot + MyBatis
- 使用MySQL + Redis
- 使用消息队列
- 部署到服务器
- 编写项目文档

**学习目标**：
- 积累项目经验
- 理解系统设计
- 提升编码能力

#### 阶段六：进阶提升（持续学习）

**学习内容**：
- JVM
  - 内存模型
  - 垃圾回收
  - 性能调优
- 并发编程
  - 线程池
  - 锁机制
  - 并发工具类
- 系统设计
  - 高并发
  - 高可用
  - 可扩展
- 源码阅读
  - Spring源码
  - MyBatis源码
  - JDK源码

**推荐资源**：
- 书籍：《深入理解Java虚拟机》《Java并发编程的艺术》
- 视频：马士兵JVM、尚硅谷并发编程

### 三、学习时间规划

**总时间**：4-6个月

| 阶段 | 时间 | 内容 |
|------|------|------|
| 第1阶段 | 4-6周 | Java基础 |
| 第2阶段 | 2-3周 | 数据库 |
| 第3阶段 | 3-4周 | Web开发 |
| 第4阶段 | 4-6周 | 框架学习 |
| 第5阶段 | 4-6周 | 项目实战 |
| 第6阶段 | 持续 | 进阶提升 |

### 四、面试准备重点

**Java基础**：
- 集合框架原理
- 多线程与并发
- JVM内存模型
- 垃圾回收算法

**数据库**：
- 索引原理
- 事务隔离级别
- 慢查询优化
- Redis数据结构

**框架**：
- Spring IoC/AOP原理
- Spring Boot自动配置
- MyBatis执行流程

**项目**：
- 项目架构
- 技术选型
- 难点与解决方案
- 性能优化
