# 操作系统学习路线

## 岗位类别
后端开发/前端开发/测试开发

## 资料类型
学习路径

## 正文内容

### 一、学习路线总览

```
操作系统基础 → 进程管理 → 内存管理 → 文件系统 → IO管理 → 系统调用
```

### 二、各阶段详细内容

#### 阶段一：操作系统基础（1-2周）

**学习内容**：
- 操作系统概述
- 操作系统功能
- 操作系统分类
- 发展历史

**推荐资源**：
- 书籍：《操作系统概念》
- 视频：哈工大操作系统

**学习目标**：
- 理解操作系统概念
- 了解操作系统功能
- 掌握基本概念

#### 阶段二：进程管理（2-3周）

**学习内容**：
- 进程
  - 进程概念
  - 进程状态
  - 进程控制
- 线程
  - 线程概念
  - 线程vs进程
  - 线程同步
- 进程调度
  - 调度算法
  - 调度策略
- 进程通信
  - 管道
  - 消息队列
  - 共享内存
  - 信号量

**推荐资源**：
- 书籍：《操作系统概念》
- 视频：哈工大操作系统

**学习目标**：
- 理解进程和线程
- 掌握进程调度
- 了解进程通信

#### 阶段三：内存管理（2-3周）

**学习内容**：
- 内存分配
  - 连续分配
  - 非连续分配
- 虚拟内存
  - 概念
  - 页式管理
  - 段式管理
- 页面置换
  - 置换算法
  - LRU
  - FIFO
- 内存保护

**推荐资源**：
- 书籍：《操作系统概念》

**学习目标**：
- 理解内存分配
- 掌握虚拟内存
- 了解页面置换

#### 阶段四：文件系统（1-2周）

**学习内容**：
- 文件概念
- 文件组织
- 目录结构
- 文件存储
- 文件保护

**推荐资源**：
- 书籍：《操作系统概念》

**学习目标**：
- 理解文件系统
- 掌握文件组织
- 了解文件存储

#### 阶段五：IO管理（1-2周）

**学习内容**：
- IO设备
- IO控制
  - 程序IO
  - 中断驱动
  - DMA
  - 通道
- IO调度
- 缓冲管理

**推荐资源**：
- 书籍：《操作系统概念》

**学习目标**：
- 理解IO设备
- 掌握IO控制
- 了解IO调度

#### 阶段六：系统调用（1-2周）

**学习内容**：
- 系统调用概念
- 系统调用类型
- 系统调用实现
- 用户态vs内核态

**推荐资源**：
- 书籍：《深入理解计算机系统》

**学习目标**：
- 理解系统调用
- 掌握系统调用类型
- 了解用户态和内核态

### 三、学习时间规划

**总时间**：2-3个月

| 阶段 | 时间 | 内容 |
|------|------|------|
| 第1阶段 | 1-2周 | 操作系统基础 |
| 第2阶段 | 2-3周 | 进程管理 |
| 第3阶段 | 2-3周 | 内存管理 |
| 第4阶段 | 1-2周 | 文件系统 |
| 第5阶段 | 1-2周 | IO管理 |
| 第6阶段 | 1-2周 | 系统调用 |

### 四、操作系统面试重点

#### 1. 进程和线程
- 进程和线程的区别
- 进程状态
- 进程调度算法
- 线程同步

#### 2. 内存管理
- 虚拟内存
- 页面置换算法
- 内存分配

#### 3. 死锁
- 死锁条件
- 死锁预防
- 死锁避免
- 死锁检测

#### 4. IO模型
- 阻塞IO
- 非阻塞IO
- IO多路复用
- 异步IO
