# Linux学习路线

## 岗位类别
后端开发/运维/SRE

## 资料类型
学习路径

## 正文内容

### 一、学习路线总览

```
Linux基础 → 常用命令 → Shell脚本 → 系统管理 → 网络管理 → 服务部署
```

### 二、各阶段详细内容

#### 阶段一：Linux基础（1-2周）

**学习内容**：
- Linux简介
- 安装Linux（虚拟机/双系统）
- 目录结构
- 文件系统
- 用户和权限

**推荐资源**：
- 书籍：《鸟哥的Linux私房菜》
- 视频：尚硅谷Linux

**学习目标**：
- 能独立安装Linux
- 理解目录结构
- 掌握基本概念

#### 阶段二：常用命令（2-3周）

**学习内容**：
- 文件操作
  - ls、cd、pwd
  - cp、mv、rm
  - mkdir、touch
  - cat、more、less
  - find、grep
- 文本处理
  - awk、sed
  - sort、uniq
  - wc、cut
- 系统信息
  - top、htop
  - df、du
  - free
  - ps、kill

**推荐资源**：
- 书籍：《Linux命令行与Shell脚本编程大全》
- 在线练习：https://overthewire.org/wargames/bandit/

**学习目标**：
- 熟练使用常用命令
- 能进行文件操作
- 能查看系统信息

#### 阶段三：Shell脚本（2-3周）

**学习内容**：
- Shell基础
- 变量
- 流程控制
  - if
  - for
  - while
- 函数
- 正则表达式

**推荐资源**：
- 书籍：《Shell脚本学习指南》
- 视频：尚硅谷Shell

**学习目标**：
- 能编写Shell脚本
- 能自动化日常任务

#### 阶段四：系统管理（2-3周）

**学习内容**：
- 用户管理
  - useradd、userdel
  - passwd、groupadd
- 进程管理
  - ps、top
  - kill、nohup
- 服务管理
  - systemctl
  - service
- 日志管理
  - journalctl
  - /var/log

**推荐资源**：
- 书籍：《Linux系统管理与网络管理》

**学习目标**：
- 能管理用户和权限
- 能管理进程和服务
- 能查看和分析日志

#### 阶段五：网络管理（1-2周）

**学习内容**：
- 网络配置
  - ip addr
  - ifconfig
  - route
- 网络诊断
  - ping
  - traceroute
  - netstat
  - ss
  - tcpdump
- 防火墙
  - iptables
  - firewalld

**推荐资源**：
- 书籍：《Linux网络管理与安全》

**学习目标**：
- 能配置网络
- 能诊断网络问题
- 能配置防火墙

#### 阶段六：服务部署（3-4周）

**学习内容**：
- Web服务
  - Nginx
  - Apache
- 数据库
  - MySQL
  - Redis
- 容器
  - Docker
  - Docker Compose
- 自动化
  - Ansible
  - Jenkins

**推荐资源**：
- Docker官方文档：https://docs.docker.com/
- Nginx官方文档：https://nginx.org/en/docs/

**学习目标**：
- 能部署Web服务
- 能部署数据库
- 能使用Docker容器化

### 三、学习时间规划

**总时间**：2-3个月

| 阶段    | 时间  | 内容      |
| ------- | ----- | --------- |
| 第1阶段 | 1-2周 | Linux基础 |
| 第2阶段 | 2-3周 | 常用命令  |
| 第3阶段 | 2-3周 | Shell脚本 |
| 第4阶段 | 2-3周 | 系统管理  |
| 第5阶段 | 1-2周 | 网络管理  |
| 第6阶段 | 3-4周 | 服务部署  |

### 四、Linux面试重点

#### 1. 常用命令
- 文件操作命令
- 文本处理命令
- 系统信息命令

#### 2. Shell脚本
- 变量和流程控制
- 正则表达式
- 自动化脚本

#### 3. 系统管理
- 用户和权限
- 进程管理
- 服务管理

#### 4. 网络管理
- 网络配置
- 网络诊断
- 防火墙
