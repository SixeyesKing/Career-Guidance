# 大厂校招流程指南

## 岗位类别
后端开发/前端开发/测试开发/算法工程师

## 资料类型
招聘流程

## 正文内容

### 一、校招整体流程

大厂校招通常包括以下环节：

```
网申投递 → 简历筛选 → 笔试 → 技术一面 → 技术二面 → HR面 → Offer → 签约
```

### 二、各环节详解

#### 1. 网申投递

**时间**：7月-10月（秋招），3月-5月（春招）

**注意事项**：
- 尽早投递，很多公司采用滚动录取
- 完善简历，突出项目经验和技术能力
- 部分公司需要填写内推码
- 一次只能投递一个岗位，流程结束后可投递其他岗位

**投递渠道**：
- 公司官方校招网站
- 牛客网、BOSS直聘等招聘平台
- 校园宣讲会现场投递
- 内推（学长学姐、校园大使）

#### 2. 简历筛选

**筛选标准**：
- 学历背景（985/211/双一流优先）
- 专业匹配度
- 项目经验
- 实习经历
- 竞赛获奖
- 技术博客/GitHub

**优化建议**：
- 突出与岗位相关的项目经验
- 量化项目成果（提升XX%、处理XX万数据）
- 使用STAR法则描述项目
- 控制在1-2页

#### 3. 笔试

**笔试类型**：
- **算法笔试**：LeetCode风格，考察数据结构与算法
- **综合笔试**：行测+专业知识
- **编程笔试**：在线编程，限时完成

**准备建议**：
- 刷LeetCode（至少100-200题）
- 复习数据结构（数组、链表、树、图）
- 复习算法（排序、搜索、动态规划）
- 熟悉在线编程环境（牛客、LeetCode）

**常见笔试平台**：
- 牛客网
- LeetCode
- 赛码网
- 公司自研平台

#### 4. 技术面试

**一面（基础面）**：
- 自我介绍
- 项目介绍（STAR法则）
- 计算机基础（操作系统、计算机网络、数据库）
- 编程语言基础（Java/Python/Go）
- 算法题（手撕代码）

**二面（深度面）**：
- 项目深挖（架构设计、技术选型、难点解决）
- 系统设计（高并发、分布式）
- 场景题（如何设计XX系统）
- 算法题（中等难度）

**面试技巧**：
- 准备1-2个亮点项目
- 能画出项目架构图
- 能解释技术选型的原因
- 能说出项目中的难点和解决方案

#### 5. HR面试

**常见问题**：
- 自我介绍
- 为什么选择我们公司？
- 你的职业规划是什么？
- 你的优缺点是什么？
- 你能接受加班吗？
- 你的期望薪资是多少？

**回答技巧**：
- 展现对公司的了解
- 表达积极的工作态度
- 展现良好的沟通能力
- 不要撒谎，保持真诚

#### 6. Offer与签约

**注意事项**：
- 仔细阅读Offer条款
- 了解薪资结构（基本工资+绩效+年终奖）
- 了解福利待遇（五险一金、餐补、房补）
- 了解工作地点和工作时间
- 确认三方协议签订时间

### 三、各公司校招特点

| 公司     | 笔试特点   | 面试特点     | 备注         |
| -------- | ---------- | ------------ | ------------ |
| 字节跳动 | 算法题为主 | 注重项目经验 | 飞书面试系统 |
| 腾讯     | 综合笔试   | 注重基础     | 面试轮次较多 |
| 阿里     | 算法+综合  | 注重潜力     | 面试周期较长 |
| 美团     | 算法题为主 | 注重工程能力 | 流程较快     |
| 快手     | 算法题为主 | 注重项目     | 流程较快     |
