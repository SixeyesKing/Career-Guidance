# 内推指南

## 岗位类别
后端开发/前端开发/测试开发

## 资料类型
招聘流程

## 正文内容

### 一、什么是内推？

内推是指通过公司内部员工推荐简历，相比普通投递有以下优势：
- 简历优先筛选
- 流程更快
- 部分公司有直通面试机会
- 可以了解公司内部情况

### 二、内推渠道

#### 1. 学长学姐
- 最常见的内推渠道
- 可以了解公司内部情况
- 可以获得面试建议

#### 2. 校园大使
- 各公司在学校设立的代表
- 通常有内推码
- 可以获得校招信息

#### 3. 牛客网
- 很多员工在牛客网发布内推信息
- 可以直接联系内推人
- 内推码分享

#### 4. 脉脉
- 职场社交平台
- 可以找到公司员工
- 可以直接联系

#### 5. GitHub
- 一些技术员工会在GitHub分享内推信息
- 可以通过项目联系

### 三、内推流程

#### 1. 寻找内推人
- 联系学长学姐
- 在牛客网搜索
- 在脉脉搜索

#### 2. 获取内推码
- 向内推人索取内推码
- 部分公司有内推链接

#### 3. 投递简历
- 使用内推码或内推链接投递
- 填写简历时注意完善信息

#### 4. 跟进进度
- 可以向内推人询问进度
- 及时反馈面试情况

### 四、内推注意事项

#### 1. 简历质量
- 内推不能保证通过
- 简历质量仍然很重要
- 项目经验要扎实

#### 2. 沟通礼貌
- 与内推人沟通要礼貌
- 不要频繁打扰
- 及时感谢

#### 3. 信息真实
- 简历信息要真实
- 不要夸大经历
- 保持诚信
