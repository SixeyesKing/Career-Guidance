# 简历投递技巧

## 岗位类别
后端开发/前端开发/测试开发

## 资料类型
招聘流程

## 正文内容

### 一、简历基本结构

#### 1. 个人信息
- 姓名、电话、邮箱
- 求职意向（岗位、城市）
- 个人主页（GitHub、技术博客）

#### 2. 教育背景
- 学校、专业、学历、毕业时间
- GPA（如果较高）
- 相关课程

#### 3. 技能清单
- 编程语言
- 框架技术
- 数据库
- 工具软件

#### 4. 项目经历
- 项目名称、时间
- 项目描述
- 个人职责
- 技术难点
- 项目成果

#### 5. 实习经历
- 公司、岗位、时间
- 工作内容
- 工作成果

#### 6. 获奖荣誉
- 竞赛获奖
- 奖学金
- 其他荣誉

### 二、简历优化技巧

#### 1. 量化成果
**不好的写法**：
- 负责系统性能优化

**好的写法**：
- 负责系统性能优化，QPS从1000提升到5000，响应时间从200ms降低到50ms

#### 2. 使用STAR法则
- **Situation**：项目背景
- **Task**：你的任务
- **Action**：你的行动
- **Result**：最终成果

**示例**：
- 在XX项目中（S），负责优化数据库查询性能（T），通过添加索引和优化SQL语句（A），查询时间从2秒降低到100毫秒（R）

#### 3. 突出技术栈
- 列出与岗位相关的技术
- 使用关键词匹配JD
- 按熟练程度排序

#### 4. 项目描述模板
```
项目名称：XX系统
项目时间：2024.03 - 2024.06
项目描述：XX系统是一个XX平台，主要功能包括XX、XX、XX
技术栈：Spring Boot + MyBatis + MySQL + Redis + RabbitMQ
个人职责：
1. 负责XX模块的设计与开发
2. 实现XX功能，解决了XX问题
3. 优化XX性能，提升了XX%
项目成果：
1. 系统支持XX用户同时在线
2. 响应时间控制在XXms以内
3. 代码覆盖率达到XX%
```

### 三、投递策略

#### 1. 投递时间
- 尽早投递，抢占先机
- 避开截止日期
- 工作日上午投递效果最佳

#### 2. 投递渠道
- 官方校招网站（优先）
- 牛客网、BOSS直聘
- 校园宣讲会
- 内推（强烈推荐）

#### 3. 内推优势
- 简历优先筛选
- 流程更快
- 部分公司有直通面试机会

#### 4. 投递记录
建议用Excel记录投递情况：

| 公司 | 岗位 | 投递时间 | 当前状态 | 笔试时间 | 面试时间 | 备注 |
| ---- | ---- | -------- | -------- | -------- | -------- | ---- |
| 字节 | 后端 | 8月15日  | 笔试中   | 8月25日  | -        | -    |

### 四、常见问题

#### 1. 简历被刷怎么办？
- 优化简历内容
- 换投递渠道（尝试内推）
- 降低目标公司层级
- 提升自身能力

#### 2. 没有项目经验怎么办？
- 做课程设计项目
- 参加开源项目
- 做个人项目
- 参加编程比赛

#### 3. 没有实习经验怎么办？
- 投递日常实习
- 参与开源项目
- 做个人项目
- 参加编程比赛
