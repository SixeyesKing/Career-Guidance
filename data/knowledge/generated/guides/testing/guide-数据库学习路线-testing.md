# 数据库学习路线

## 岗位类别
后端开发/测试开发

## 资料类型
学习路径

## 正文内容

### 一、学习路线总览

```
SQL基础 → MySQL → Redis → MongoDB → 数据库设计 → 性能优化
```

### 二、各阶段详细内容

#### 阶段一：SQL基础（1-2周）

**学习内容**：
- SQL语法
  - SELECT查询
  - INSERT插入
  - UPDATE更新
  - DELETE删除
- 数据类型
- 约束（主键、外键、唯一、非空）
- 聚合函数
- 分组查询
- 连接查询
- 子查询

**推荐资源**：
- 书籍：《SQL必知必会》
- 在线练习：https://www.sql-ex.com/

**学习目标**：
- 熟练编写SQL语句
- 理解关系型数据库概念
- 掌握复杂查询

#### 阶段二：MySQL（3-4周）

**学习内容**：
- 存储引擎
  - InnoDB
  - MyISAM
- 索引
  - B+树原理
  - 索引类型
  - 索引优化
- 事务
  - ACID特性
  - 事务隔离级别
  - 锁机制
- 性能优化
  - 慢查询分析
  - EXPLAIN使用
  - SQL优化

**推荐资源**：
- 书籍：《MySQL必知必会》《高性能MySQL》
- 视频：尚硅谷MySQL

**学习目标**：
- 理解MySQL架构
- 掌握索引原理
- 能进行SQL优化

#### 阶段三：Redis（2-3周）

**学习内容**：
- 数据结构
  - String
  - List
  - Set
  - Hash
  - ZSet
- 持久化
  - RDB
  - AOF
- 应用场景
  - 缓存
  - 分布式锁
  - 计数器
  - 排行榜

**推荐资源**：
- 书籍：《Redis设计与实现》《Redis深度历险》
- 视频：尚硅谷Redis

**学习目标**：
- 掌握Redis数据结构
- 理解持久化机制
- 能设计缓存方案

#### 阶段四：MongoDB（1-2周）

**学习内容**：
- 文档存储
- CRUD操作
- 索引
- 聚合管道
- 副本集
- 分片

**推荐资源**：
- 官方文档：https://www.mongodb.com/docs/

**学习目标**：
- 理解文档数据库概念
- 掌握基本操作
- 了解应用场景

#### 阶段五：数据库设计（1-2周）

**学习内容**：
- 范式理论
  - 第一范式
  - 第二范式
  - 第三范式
- ER图
- 表设计原则
- 索引设计

**推荐资源**：
- 书籍：《数据库系统概论》

**学习目标**：
- 能设计合理的数据库结构
- 理解范式理论
- 掌握索引设计

#### 阶段六：性能优化（持续学习）

**学习内容**：
- 查询优化
- 索引优化
- 架构优化
  - 读写分离
  - 分库分表
  - 缓存策略

**推荐资源**：
- 书籍：《高性能MySQL》

**学习目标**：
- 能分析慢查询
- 能优化SQL语句
- 了解架构优化

### 三、学习时间规划

**总时间**：2-3个月

| 阶段 | 时间 | 内容 |
|------|------|------|
| 第1阶段 | 1-2周 | SQL基础 |
| 第2阶段 | 3-4周 | MySQL |
| 第3阶段 | 2-3周 | Redis |
| 第4阶段 | 1-2周 | MongoDB |
| 第5阶段 | 1-2周 | 数据库设计 |
| 第6阶段 | 持续 | 性能优化 |

### 四、数据库面试重点

#### 1. MySQL
- 索引原理（B+树）
- 事务隔离级别
- 锁机制
- 慢查询优化

#### 2. Redis
- 数据结构
- 持久化机制
- 缓存穿透、击穿、雪崩
- 分布式锁
